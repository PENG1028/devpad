# DevPad

本地优先的 Windows 开发笔记本：记录 → 整理 → 选择 → Copy for Agent。

当前桌面版 0.6.5（图片标注、统一下拉框与批量复制修正）：双击 `release/DevPad-0.6.5.exe`。请先从托盘退出旧版，再打开新版，沿用原来的本地数据目录。首次启动自动备份数据库，并将旧的已忽略笔记恢复为待处理。

## 开发

运行 `powershell -ExecutionPolicy Bypass -File scripts/dev.ps1`。编译运行 `powershell -ExecutionPolicy Bypass -File scripts/build.ps1`。脚本只为当前进程添加 Rust 路径，不修改系统环境变量。Node 依赖安装在本项目 `node_modules`。

## 使用

- 每次点击“记点什么”或在主窗口按 Ctrl+N，新开一份独立草稿。主列表粘贴文字、截图或拖入图片会新开笔记；编辑器内粘贴只修改当前草稿。
- 笔记右上角的三个点提供“编辑”和“移动到其他项目”。同一条笔记重复打开会聚焦已有编辑窗口，不覆盖未保存内容。点击保存或 Ctrl+Enter 保存成功后关闭当前笔记窗口；再次记录时重新点击“记点什么”。保存失败保留输入。
- 编辑器的“所属项目”可以修改新笔记或已有笔记的位置，保存前保留所有输入。原有引用不丢失，跨项目引用显示来源项目。
- “返回列表”隐藏当前编辑窗口；主窗口的“已打开笔记”可恢复。窗口关闭和程序退出分别检查未保存内容；退出时逐个确认，取消不会丢弃已确认窗口里的草稿。
- 每条笔记右上角、三个点左边的圆形按钮直接复制 Agent 提示词。悬停或键盘聚焦时，它向左展开为三个圆形操作：原文、图片（有图时）、Agent 提示词；滚动列表即收起。三个点菜单也会随列表滚动关闭。
- 笔记标题右侧“多选”直接进入选择模式；支持全选、清空、Shift 连选以及行内“选择到这里”；批量栏直接显示复制提示词、复制图片（有图时）、复制原文，并提供“移动项目”。修改筛选或项目时清空选择，避免对隐藏记录操作。
- 单条与多选复制使用独立交付批次，同一内容的提示词和图片编号一致。单条菜单中的“交给 Agent”或复制后的“查看上次交付”打开对应快照，也可以导出附件包。内容改变后需重新复制配套文本和图片。
- 交付窗口固定打开时的内容，不跟随主列表的项目或选择变化。源笔记或引用修改、迁移、删除时仅提示；需要最新版本请从列表重新交付。每个交付窗口独立排序与复制。
- 状态只保留待处理、已完成，可单条或批量恢复待处理。旧 Ignore 记录自动恢复待处理。项目侧栏可按类型、标签和状态筛选，条件均可清除。
- 主题支持浅色、深色和跟随系统。Ctrl+F 搜索；Alt+1…6 选择笔记类型；输入区外 Ctrl+A 全选当前结果。
- 主窗口关闭后收进托盘；托盘恢复此前可见的窗口。设置中可以退出程序或启用开机静默启动。
- 笔记本模式可将主窗口收成悬浮图标，默认关闭；辅助窗口显示时暂停收起。收起和展开都由同一个原生窗口在约 280 毫秒内改变实际边界。收起落到标题栏收起按钮的位置；展开时根据屏幕工作区选择方向并固定相应角，内容淡入淡出。悬浮图标为 36×36，使用系统原生拖动，无额外悬停底色或文字提示；列表、筛选与滚动位置保留。拖动小图标后，按新位置确定展开方向，空间不足时限制展开尺寸；系统启用减少动态效果时直接切换。主窗口最小 400×320，编辑和交付窗口最小 420×380，标题栏不随正文滚动。

## 验证

日常 UI 检查使用 `npm run build` 后运行 `npm run test:ui:headless`，它仅使用无界面浏览器和临时页面数据，不连接桌面程序，也不操作系统鼠标或剪贴板。以下原生脚本属于手动验收工具，未经明确安排不要运行，以免影响其他桌面工作。

`npm run check`、`npm test`、`cargo test --manifest-path src-tauri/Cargo.toml` 检查前端与数据库/附件逻辑。

原生验收使用 `tests/batch-78.cjs`（`npm run test:native`）。启动测试程序时须设置全新的 `DEVPAD_DATA_DIR`（路径含 `78F1BC58`）与 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9238`，然后运行测试。脚本会修改测试数据与剪贴板，完成后关闭测试程序；不应连接日常使用的实例。`DEVPAD_TEST_PORT` 可覆盖端口。

## 数据与边界

数据目录：`%APPDATA%\local.devpad.desktop`。数据库为 `devpad.sqlite`，图片存放在 `attachments`，复制图片的临时包在 `exports`。从托盘菜单彻底退出应用后，复制整个目录即可备份。删除记录不会自动删除附件；恢复数据库备份时仍可找到图片。`exports` 中不再需要的包可手动清理。

如需隔离测试或自定义存储，可以在启动进程前设置 `DEVPAD_DATA_DIR` 为专用目录；普通使用无需设置。

没有云端、账号、AI API、通知中心、看板或剪贴板后台轮询。本版没有全局快捷输入窗口。草稿保存在当前进程内存中，未提供崩溃恢复。系统剪贴板无法保证所有 Agent 都一次接收多张图和文字，因此不将此行为标为已支持。未签名的本地构建不等同于正式发布安装包。

设计与技术说明见 [docs/design.md](docs/design.md)。安装记录见 [docs/installation.md](docs/installation.md)。


编辑器中，附件缩略图的“标注”支持画圈、画笔、箭头、颜色与撤销。应用标注另存图片，保存笔记后生效，原图文件保留。下拉框统一支持键盘方向键、Enter 和 Escape。
