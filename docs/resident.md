# 0.4.0：托盘常驻与开机自启

主窗口关闭按钮和 Alt+F4 收进托盘，同时隐藏辅助窗口。已有编辑内容保留在当前进程中；点击托盘图标重新打开，未保存的编辑窗口也会恢复。标准最小化仍进入任务栏，靠边收起仍保留边缘细条，两者不互相替代。

托盘右键提供打开和退出，设置提供同一个退出入口。退出时，在写笔记窗口内使用统一确认框处理未保存内容；正在处理图片或保存时阻止退出。明确放弃后才结束进程。关闭到托盘不等同于写入磁盘，进程崩溃、强制结束或关机前仍需保存笔记。

开机自启默认关闭。开启时只写当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\DevPad`，内容为带引号的完整 EXE 路径与 `--autostart`；关闭时删除该值。不创建服务或计划任务，不需要管理员权限。显式重新启用时清除 Windows 为该项目留下的禁用标记。测试模式写独立的 `HKCU\Software\DevPad\TestStartup`，不会注册真实启动项。便携版移动程序后应重新设置自启。

自启模式先创建托盘，主窗口保持隐藏。正常重复运行由官方单实例插件唤回已有进程；重复的自启调用不打断前台。

依据：[Tauri 系统托盘](https://v2.tauri.app/learn/system-tray/)、[Tauri 单实例](https://v2.tauri.app/plugin/single-instance/)、[Microsoft 当前用户登录启动项](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)。
