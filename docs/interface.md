# 界面与语言规范

## 字体和布局

| 位置 | 字号和字重 | 使用方式 |
| --- | --- | --- |
| 项目名、项目行和操作菜单 | 14px / 400 | 选中项目用淡色背景和 2px 竖线，保持字宽稳定 |
| 侧栏分组、日期 | 15px / 500、14px / 500 | 通过字号和留白区分分组 |
| 记录正文 | 15px / 400，行高 1.6 | 按用户输入保留分段，随文本确定书写方向 |
| 设置行和辅助说明 | 14px / 400、12px / 400 | 字段名和说明在阅读起始侧，选择器和开关在行尾 |

主窗标题栏高 48px，工具和窗口按钮共享 24px 中心线。主窗按钮从项目名之后依次为搜索、多选、悬浮笔记本和更多。窗口按钮保留靠右的完整点击区域。中文简体使用随程序附带的 Noto Sans SC。日文、韩文和繁体中文优先使用对应的系统字体。阿拉伯语面板和项目列表按从右到左排列。

设置的「通用」放主题、语言和桌面行为。「工具」放记录、模板和 Agent 集成。「关于」放帮助、更新、应用内快捷键和存储位置。标签栏支持左右方向键、Home 和 End。短窗口可以滚动设置内容。单条记录菜单用分隔线分开编辑与复制、移动与导出等操作、删除。导出面板默认提供原文与原图，可切换到模板。

标题栏的「更多」在当前窗口打开设置。记录旁的三个点打开该记录的操作菜单。多选时，每条记录右侧都有「选择到这里」按钮。它从上一次勾选的位置选到目标，两端都包含。没有起点时从当前列表第一条开始。已有选择会保留，切换项目或筛选会清空选择。

有图有字时，快捷复制和多选栏的 Ctrl/Cmd+C 同时复制图文。在 Windows 上，剪贴板包含按笔记排列的图文、原图文件列表和纯文字。纯文字在相应正文下面列出原文件名。将鼠标移到复制按钮上或在按钮上按向下键，可以单独复制正文或图片。触屏也可以从记录菜单选择。仅有文字时直接复制正文，只有一张图时直接复制图像。

## 增加或更新语言

语言清单在 `src/locales/registry.json`。每项声明语言代码、自称、地区别名、Windows 安装器语言，以及需要时的书写方向。设置页、系统语言匹配和原生窗口读取同一份清单。语言偏好存入本机应用数据库，打开的界面通过窗口间同步接收变化。

界面消息使用中文源句作为键，英文对照登记在 `src/locales/messages/en.json`。其他语言各自维护同名键，简体中文直接显示源句。使用 Svelte 的 `$t` 和 Rust 的 `Language::text` 查找文案。动态值用 `{count}` 这样的具名占位符传入。模板的 `{{content}}` 等变量是用户可编辑的导出格式。项目名、正文、文件名和自定义模板保留原文。

1. 新增文案时登记英文对照和各语言译文。新增语言时登记语言清单、对应的翻译文件和安装器语言。
2. 译文校对完成后运行 `npm run locales:review -- ja`，将 `ja` 换成刚完成校对的语言。英文原句变化时，之前的校对记录会失效。
3. `npm run check:locales` 检查缺项、多余键、重复键、空译文、占位符、未登记的界面文字和校对状态。此检查在测试和生产构建前自动运行。
4. `npm run test:ui:headless` 在编译后的界面中逐项切换注册语言，检查窄窗排版、文字方向、打开窗口的同步以及自定义内容。原生测试另行覆盖托盘语言、窗口标题和重启后的偏好。
