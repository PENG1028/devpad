# 0.6.3 · 同一窗口展开与收起

本轮仅调整悬浮笔记本与主窗口之间的形变，替换 0.6.2 的双窗口交接方式。

- 从收起到展开始终使用主窗口的同一个原生窗口句柄和页面实例，不创建替代悬浮窗口。
- 根据窗口与屏幕工作区四边的距离确定固定角。右上方窗口固定右上角，向左下展开，向右上收起；其余方向对称处理。
- 原生位置与尺寸在约 280 毫秒内同步更新，每帧从固定角反算位置，避免左右边缘舍入误差造成漂移。两个方向使用同一条平滑曲线。
- 图标和笔记内容在同一表面内淡入淡出。列表、筛选、选择与滚动位置保持；紧凑模式禁用笔记页面的键盘和粘贴入口。
- 拖动后按新位置重新选择固定角；若可用空间不足，限制展开尺寸，保持固定角的位置。支持负坐标显示器和工作区边界。
- 托盘隐藏保留紧凑状态，恢复时展开同一窗口；展开恢复原先的置顶设置、任务栏入口和可调整尺寸状态。动画初始化或尺寸操作失败时尝试恢复完整窗口。
- 系统开启减少动态效果时直接切换尺寸。

验证：前端类型检查 0 错误、0 警告；三项 Rust 几何测试通过，覆盖四角固定与逆向恢复、负坐标显示器、拖动后可用空间约束。隔离无界面浏览器检查通过，覆盖页面实例保留、滚动恢复、过渡就绪通知和紧凑模式输入隔离。

没有启动桌面程序、操作系统鼠标或切换用户窗口；Windows 上实际动画的流畅度、边缘绘制与混合缩放观感尚未实机验收。

交付：`release/DevPad-0.6.3.exe`，校验文件 `release/SHA256-0.6.3.txt`。本轮没有数据库结构或笔记内容变更。
