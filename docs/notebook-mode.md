# 0.6.0：侧边栏、手动悬浮与图内编号

左上项目与筛选在主窗口宽度至少 760、高度至少 460 逻辑像素时展开 280 像素侧边栏；更小的窗口使用独立筛选窗口。切换布局传递当前项目、筛选条件及正在输入的新项目名。编辑、设置、交付与图片预览仍是独立窗口。

手动“收起为悬浮笔记本”按钮始终显示，不依赖自动模式开关。悬浮笔记本为 40×48 逻辑像素；拖至屏幕外边缘变为 9 像素小点，命中区仍为 24×24。只有主列表参与自动收起，辅助窗口不参与。

交付图片上方增加浅色编号条，例如“记录 01 · 图片 02 / A1B2C3D4”。编号属于交付副本的图片像素；上传方改名或重排后仍可按图内编号核对。文本引用相同的批次、记录和图片编号。原图文件、原始记录、附件顺序和状态均不修改。PNG/JPG/WebP 的交付副本统一为 PNG，不缩放或裁剪原图区域；极窄图片会补横向空白，以完整显示编号。

交付预览内容或顺序改变后生成新批次。已经复制的内容若属于旧批次，显示重新复制提示。每次复制和导出捕获一致的快照；处理过程中禁用顺序调整。Done / Ignore 记录在输出说明中作为背景参考。

先粘贴文本，再复制并粘贴图片文件。接收端仍须支持文件列表粘贴；不支持时使用上传或导出附件包。图内标注不保证模型永远识别正确，模糊或缺图时要求模型明确指出。未承诺一次混合粘贴文字与多图。

渲染在后台任务中逐张完成，使用 Windows 自带字体和现有图片库，无在线字体或服务。复制用副本仍存于本地数据目录 exports 下，保留到剪贴板使用之后；本轮未新增自动清理或存储迁移功能。

# 0.5.0：笔记本模式与简洁交付

模式默认关闭，只作用于主列表。启用后，鼠标连续离开 30 秒会收成约 64×72 逻辑像素的悬浮笔记本；也可设置 15 秒或 1 分钟，主窗口工具栏有主动收起入口。悬浮窗口仅显示笔记本图标，可以拖动和点击。

悬浮笔记本拖到显示器桌面外侧的左、右、顶部，收成约 9 像素的点，点击/拖动命中区为 24×24。拖离边缘恢复小笔记本，拖动不会误打开主列表；点击或键盘 Enter 恢复原尺寸列表。移动后的展开位置跟随悬浮笔记本并限制在当前屏幕工作区；未移动时恢复原位置。

完整窗口不再因靠边而自动收起。悬浮笔记本通过自身拖动处理移动，不调用 Windows 标题栏拖拽，减少与系统贴靠的竞争。两个屏幕相接的内部边缘不吸附，不处理底部任务栏。

设置、编辑、筛选、交付和图片预览保持普通辅助窗口。任一辅助窗口可见时暂停自动收起；鼠标在主窗口内、键盘输入、原生拖动、最大化、最小化和托盘隐藏时不自动收起。关闭到托盘和明确退出的语义不变。

这是交互模式改造，未声称降低已有约 100 MiB 的私有驻留内存；隐藏期间保留笔记状态，小悬浮窗口也使用 WebView2。

## 交付与图片对应

界面仅保留输出数量、顺序、文本预览、复制提示词/复制图片文件/导出附件包，以及一句粘贴说明。所有选中记录合成一份文本；Draft 引用紧跟该记录按引用列表展开，重复记录去重。

默认按创建时间从早到晚；也可选择从晚到早或选中顺序。预览和复制使用同一结果。图片按输出记录顺序、再按记录内附件顺序编号，名称为 `001-原图名称.png` 一类；同名原图也因序号而区分。合法化名称只影响交付副本，不重命名真实附件或改写笔记。

先粘贴文本，再复制并粘贴整组图片。更改顺序或选择后，应重新复制文本和图片，不能把两次不同交付结果混用。目标 Agent 若丢弃文件名或调整图片顺序，不能保证仅靠文件名还原对应关系；这种情况下应使用附件包或分批上传核对。应用没有宣称所有 Agent 支持一次混合粘贴文字与图片。

自动收起计时在原生桌面线程中进行，避免页面被遮挡后的浏览器计时节流；主窗口的忙碌状态和自定义确认框会向原生层发送暂停状态。

桌面小窗口测试使用真实原生窗口缩放，不再用浏览器视口模拟。视口模拟曾造成 400×320 网页嵌在 1040×780 原生窗口内的白色空白；已通过对齐原生窗口和网页内容尺寸验证原因。
