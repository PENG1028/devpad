# DevPad 黑白主题界面改造

以用户提供的黑白参考图为视觉方向：系统字体、黑白灰、细分隔线，蓝色仅用于主要操作和少量交互反馈。桌面默认 1040×780，最小 520×480。没有在线字体、图片背景、云服务或新的 AI 功能。

## 入口映射

| 功能 | 入口 |
| --- | --- |
| 项目切换、新建 | 顶部项目名 |
| 项目、类型、标签、状态筛选 | 左上菜单；选中条件保留在主界面，可清除 |
| 搜索 | 顶部搜索或 Ctrl+F |
| 新建、继续记录 | 底部轻量输入条；Ctrl+N |
| 类型、标签、图片、保存 | 输入条展开后的编辑器 |
| Draft 及引用排序 | 编辑器类型选择 Draft；更多菜单也提供入口 |
| 编辑、单条状态、删除 | 每条笔记的更多按钮或右键 |
| 多选、连续选择和批量处理 | 顶部更多 → 选择笔记；Ctrl+A；Ctrl/Shift 点击 |
| Copy for Agent | 选择模式操作栏，或单条笔记菜单 |
| 提示词、图片复制和附件导出 | 按需弹出的交付预览 |
| 浅色/深色/跟随系统 | 顶部更多 → 外观 |
| 置顶 | 顶部图钉按钮 |
| 窗口拖动、缩放、最小化、关闭 | 自定义标题栏调用原生 Tauri 窗口接口 |

## 实现边界

Rust 数据库、附件导入、剪贴板、导出命令及 core.ts 提示词生成均沿用原实现，数据库标识与位置不变。没有迁移或改写真实笔记内容。以原文第一行作为视觉标题，其余原文按段落展示；没有自动生成标题或替换内容。

界面由纵向布局组成：标题栏、可选搜索/筛选、可滚动笔记、底部编辑/选择区域。底部区域实际占位而非覆盖列表；小窗口通过缩小编辑器内部滚动区保持保存按钮可见。菜单与预览使用原生 dialog 的焦点限制和 Escape 关闭。未保存编辑在收起时保留，关闭原生窗口时提示。

窗口权限只增加最小化、最大化切换、关闭、拖动、置顶和主题设置；没有全局快捷键或后台轮询。窗口置顶适用于当前主窗口，本轮未新增多个便签窗口。

## 验证

tests/redesign-ui.cjs：隔离模拟 IPC，检查浅深主题、筛选、搜索、快捷保存、Draft 引用排序、多图、Shift 多选、交付预览、长文本、空状态，以及 520×480 下的横向溢出和底部遮挡。截图使用测试记录，不写入正式数据库。

tests/redesign-native.cjs：隔离原生数据目录，检查置顶/取消置顶、最大化/还原、最小化、未保存关闭保护、主题持久化、真实截图粘贴、图片显示、编辑、Unicode 文本与 CF_HDROP 图片剪贴板、批量状态和 SQLite 重载。

测试使用此电脑已安装的 Playwright 和 Edge，无新增开发依赖。先运行界面测试生成图片 fixture；原生测试需使用独立 DEVPAD_DATA_DIR，并仅为测试进程启用本机 WebView2 调试端口 9227。
