# 0.3.0：靠边隐藏、稳定主题和统一标题栏

把主窗口拖近显示器工作区的左、右或上边缘，松开鼠标后约 0.4 秒收起，边缘只留下细条。点击细条滑出原窗口，尺寸和笔记状态保留。鼠标离开后再次收起；拖离边缘恢复普通窗口。设置中的“靠边自动隐藏”可关闭这项行为。最小化按钮保持进入任务栏的标准行为。

细条为约 12×64 逻辑像素，顶部为 64×12，会随屏幕缩放调整。它不带 Windows 阴影隐藏边框，并在主窗口收起完成、细条页面准备好之后才显示。窗口移动动画约 0.15 秒，减少动画偏好开启时直接切换。

坐标使用物理像素及当前显示器工作区。负坐标显示器和缩放比例纳入计算；相邻显示器的内部接缝不触发收起，底部任务栏边缘也不触发。最大化、最小化及拖动未松开时不收起。

主题闪烁修复：之前的各窗口在收到主题存储事件后又写回主题，同时调用原生窗口主题接口，形成反馈。现在只在用户选择时写入，其他窗口读取最新值，不反向写入，也不反复修改原生窗口主题。窗口完成主题与内容初始化后显示。

主窗口、写笔记、设置、项目筛选、交付和图片预览全部使用自定义标题栏。辅助窗口保留拖动、双击最大化、置顶、最小化、最大化/还原和关闭，沿用统一的黑白视觉与未保存确认框。

没有修改数据库格式、附件目录或真实笔记内容，也没有新增依赖和全局快捷键。
