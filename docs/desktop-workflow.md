# 桌面交互版 0.3.0

本轮针对实际使用中的截图粘贴失败、小窗口拥挤、设置挤在主窗口、状态操作难找和 Agent 交付步骤不清楚进行了调整。数据库、附件路径及提示词生成方式沿用原有实现，没有新增依赖、在线字体、服务或 AI 功能。

## 窗口与返回逻辑

- 主窗口只显示列表、搜索筛选条件和轻量新增入口。400×320 时收起重复的页内大标题，保持正文正常字号。
- 选择模式只显示固定批量栏，包含退出选择入口，不与输入条争用阅读空间。
- 写笔记使用独立窗口。“返回列表”隐藏而不销毁编辑窗口，保留当前文字、附件、类型、标签和 Draft 引用。再次新增会继续这个草稿；改为编辑另一条笔记前会确认是否放弃当前内容。
- 设置、项目/筛选、交付和图片预览使用独立原生窗口，统一的自定义标题栏支持移动、置顶、最小化、最大化和关闭。重复打开会复用已有窗口，不产生重复设置页。
- 切换主列表的项目不会偷偷改变正在编辑的草稿所属项目，写笔记窗口顶部始终显示其项目。
- 主窗口正常退出前检查编辑窗口，包括已隐藏的草稿。有未保存内容时会返回编辑窗口；实际退出后辅助窗口一并关闭。
- 拖近屏幕左、右或上边缘后，主窗口滑出并隐藏，保留尺寸和置顶设置。边缘留下约 12×64 逻辑像素的置顶细条，点击滑出原窗口；鼠标离开后再次收起。拖离边缘恢复普通模式。没有新注册全局快捷键，也没有定时读取剪贴板。

## 输入与状态

在列表或正文编辑区按 Ctrl+V 时，由本地 Windows 剪贴板接口读取图片、图片文件列表或文字。正文按光标位置插入；搜索、标签及其他输入框保留普通粘贴行为。导入支持 PNG、JPG、WebP，单张上限 25 MB。拖到主窗口任意位置会导入到写笔记窗口；文本区、输入条的拖放不会重复导入。

所有记录显示待处理、已完成或已忽略。三个点可悬停展开，也支持点击、键盘和右键；完成、重新打开、忽略和删除可直接选择。删除保留原有确认。列表和其他窗口通过本机事件同步数据库变更。

交给 Agent 使用独立窗口，明确区分复制提示词和复制图片两个步骤，保留 Draft 引用展开、排序、图片去重和导出附件目录。接收方是否支持文件列表粘贴由其输入框决定，无法代替目标软件的附件接口。

## 动效

菜单淡入并轻移、搜索和选择栏展开、状态更新和新增记录淡入、拖入图片的整窗反馈、独立窗口内容出现。动效约 160–180 ms，不缩放正文和整个窗口，不延迟保存或删除。系统减少动画偏好会停用这些过渡。

## 边界

当前是一个主列表加一个可保留草稿的编辑窗口，并非每条已保存笔记都拥有独立悬浮窗口。已实现左、右、上边缘自动收起与点击展开，使用显示器工作区坐标并避开多屏相邻接缝；不在任务栏底边收起。托盘和多便签分别常驻桌面尚未实现。保存为手动保存；异常断电/强制结束进程的未保存草稿恢复不在本轮实现中。

测试使用项目 `.tools` 内隔离数据库与独立 WebView2 用户目录，不改写真实笔记。旧版退出后已备份至 `.tools/DevPad-0.1-backup.exe`，原启动路径 `release/DevPad.exe` 更新为 0.2.0。

## 焦点与确认提示修订

移除输入框、按钮和选择状态的蓝色大描边，改为输入时细灰线、键盘操作时细灰色焦点提示。所有放弃编辑、删除、切换和未保存关闭提示统一使用 DevPad 黑白确认框；取消按钮优先获得焦点，Esc 安全取消。移除浏览器 confirm 与 beforeunload 默认提示，原生窗口退出保护仍然保留。文件选择/导出继续使用 Windows 系统文件对话框。

## 主题稳定性修订

主题只在用户主动选择时写入本地设置。各窗口收到存储事件后只读取最新值，不再反向写回，也不反复修改原生窗口主题。新窗口在完成主题和内容初始化后显示，使用统一自定义标题栏。
