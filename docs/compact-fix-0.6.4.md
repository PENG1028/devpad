# 0.6.4 · 悬浮图标、拖动与收起终点

针对三张截图中的外层透明框、图标变窄、悬停底色和原生文字提示，以及拖动松手后仍跟随鼠标的问题进行修正。

- 紧凑窗口从 40×48 改为 36×36，图标直接填满组件，去掉图标素材自带的外侧留白。收起前关闭原生窗口阴影与其边缘区域，展开后恢复。
- 悬浮按钮不再继承普通按钮的悬停背景、边框、位移和旋转；移除原生 `title` 提示。键盘仍有可访问名称，聚焦仅轻微提亮图标。
- 删除排队读取鼠标位置并移动窗口的 JavaScript 链。超过拖动阈值后进入 Windows 原生移动循环，松手返回；鼠标已经释放时不再开始移动。拖动完成后才执行原有边缘停靠。纯点击继续展开。
- 手动和自动收起均读取标题栏收起按钮的实时位置，将其转换为屏幕物理坐标作为动画终点，不再按屏幕区域选择收起角落。
- 展开时始终根据当前图标位置与工作区判断方向，即使图标尚未拖动，也不复用收起方向。

验证：前端类型检查 0 错误、0 警告；Rust 检查通过。无界面浏览器检查覆盖手动/自动收起终点、图标 36×36 边界、无悬停底色与提示、单次原生拖动交接、释放后再次点击，以及原有列表状态保留。检查曾捕获并修正遗留悬停旋转造成的边界超出问题。

未启动桌面程序，也未操作系统鼠标或剪贴板。实际 Windows 拖动流畅度、原生边缘绘制及混合 DPI 观感仍需在使用中确认。

发布文件：`release/DevPad-0.6.4.exe`，校验文件：`release/SHA256-0.6.4.txt`。本轮没有数据库改动。
