Use case: ui-mockup.
Generate ONE beautiful high fidelity UI concept image comparing LIGHT and DARK appearance of DevPad, a Windows desktop local notebook for collecting development feedback and copying selected notes to an agent. The user explicitly rejected an earlier dashboard-like design. Start completely fresh. This design must feel like the extraordinarily minimal, quiet, refined native Apple Notes / iOS interface language thoughtfully adapted to a desktop window. This is a visual concept, not code.

COMPOSITION: a single landscape design sheet, two equal front-facing desktop app windows side by side, LIGHT on left and DARK on right, same content and layout. Each window is landscape-ish, generous width, NOT an iPhone, no device mockup. Image overall about 2:1. Neutral light gray surrounding canvas, narrow margins. Tiny captions outside windows only: "DevPad · 浅色" and "DevPad · 深色". Windows fill almost the whole image. No big presentation headline, swatch palettes, annotations, extra component panels or marketing slogans. Razor sharp legible Chinese UI.

ART DIRECTION: extreme visual restraint. Apple-like typography, harmonious spacing and impeccable alignment. Main canvas one continuous surface, no boxes around each note, no dashboard, no permanent sidebar, no right panel, no multicolor chips, no purple, no graphite sidebar attached to white content, no neon, no gradients, no decorative illustration. Light appearance: pure white #FFFFFF, subtle neutral input surface #F5F5F7, near black #1D1D1F text, accessible secondary gray #6E6E73. Dark appearance: entire window near black #101012, elevated small input #202023, offwhite #F5F5F7 text, secondary #A1A1A6. System blue #007AFF light / #0A84FF dark used on just a few tiny interactive accents, not big colored rectangles. Very subtle separators, not around every element. 12-16px rounded native controls; window outer corner 18px with very soft restrained shadow. Flat surfaces; slight translucency reserved only for compact bottom compose bar. SF Pro-like Latin and PingFang-like Chinese typography. Delicate consistent 1.5px stroke icons. Native desktop aspect and proportions; no Mac traffic light dots, no phone status bar or bottom home indicator.

EACH WINDOW:
Top slender toolbar, discreet sidebar toggle glyph on far left; centered compact clickable project name "DevPad" with tiny downward chevron; on right search magnifying glass and ellipsis icon, widely comfortably spaced. All icons neutral gray. Project chooser and category filters stay hidden behind these explicit controls. No breadcrumb, no logo tile, no loud create button.
Main reading column starts below toolbar, width roughly 80% of window, centered. A strong but not oversized heading "随手记" in 27px equivalent. Immediately beneath a very subtle small "今天" in gray, no slogan or counts or status badges.
Three beautifully typeset note rows with plenty of breathing room but no wasteful hero area. First row title "切换仓库后，库存没有刷新" in 17px semibold, second line in readable secondary gray "切换到 B 仓库后，列表仍显示之前的数据。" Then a single small rounded screenshot thumbnail approx 112x68 px of a neutral inventory table with no large logo; beneath or beside discreet gray caption "1 张图片 · 11:31". No bug pill, no colored tags, no visible checkbox.
Second row title "保留筛选后的滚动位置", second line "返回列表时，希望能接着上次的位置继续查看。", discreet gray timestamp "10:24". A hairline partial-width separator may divide rows.
Then understated section label "昨天" and third row title "整理好，再交给 Agent", second line "把相关记录放在一起，复制完整上下文。", timestamp "18:40".
Content uses consistent left alignment. No card boxes around notes. No huge letter spacing. Typography and negative space create hierarchy; enough content to feel like a usable notebook, not an empty landing page.
At bottom, anchored inside window with comfortable 22px margins, a SINGLE compact rounded capture bar: small plus icon on left, placeholder "记点什么…" in middle, on far right a subtle compose/pencil icon in system blue. This bar expands into full editor only when activated, but show collapsed resting state here. Its surface slightly elevated neutral gray in light, slightly lighter charcoal in dark, thin subtle outline, no heavy shadow. No seven type buttons, no attachment toolbar, no Save button in resting state.
No permanent action bar. Multi-select and "Copy for Agent" live inside contextual ellipsis actions, not shown until requested. No visible extra features such as cloud, AI chat, account, settings rail, tasks dashboard, calendar or notifications.

The two appearances must be exact counterparts: same alignment, same note content, same thumbnail, same controls, preserving legibility in both. Show calm, confident, exceptionally polished UI that feels almost invisible. The result should communicate that features are progressively disclosed, through the few discreet entry points, rather than crammed on the screen. Beautiful and realistically implementable.
