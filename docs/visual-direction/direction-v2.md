# DevPad 视觉方向 v2

用户已否定 v1。v1 的石墨侧栏、紫色配色和常驻工具布局不再作为推荐方案。此文件优先于 README.md 中的旧方向；仅设计，不修改功能代码。

采用 iOS 式极简，白与近黑两种完整主题，正文优先、系统蓝仅点缀动作。默认只展示项目切换、侧栏入口、搜索、更多、记录内容与底部输入条。

渐进展开的功能安排：
- 项目名下拉：项目切换与新建项目。
- 左上侧栏入口：类型、状态、标签筛选；退出筛选面板后，生效条件应在主视图以可清除的简短提示呈现。
- 底部输入条：点击展开编辑，显示类型、标签、附件和保存；Draft 类型展开引用排序。
- 顶部更多：进入选择模式；选择后出现完成、更多和 Copy for Agent。桌面端可辅以右键，不能仅靠悬停或手势发现功能。
- Copy for Agent：按需弹出预览，保留复制提示词、复制图片和导出附件包，完成后收起。

配色：浅色 #FFFFFF / #F5F5F7 / #1D1D1F / #6E6E73；深色 #101012 / #202023 / #F5F5F7 / #A1A1A6。动作蓝分别 #007AFF / #0A84FF。使用统一线性图标、细分隔线和克制圆角，不使用彩色分类卡片。中文保持易读的系统字体，正文建议 14–16px。
