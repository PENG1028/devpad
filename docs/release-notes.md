DevPad 产品化开发版：

- 默认普通笔记；固定复制按钮，正文复制不附带工程指令。
- 可选和自定义导出模板，多选完整导出所有图片与对应清单。
- 编辑草稿自动保存，关闭与退出后可恢复。
- 本地 stdio MCP：笔记、原图、已发布任务的领取、续期、释放和结果回写。
- 乐观版本检查、任务租约与领取凭证，避免并发覆盖。
- 应用内开发版/稳定版更新，验证签名并在安装前备份数据库。
- Windows 固定安装位置及旧快捷方式迁移；macOS 两种架构；Linux AppImage 与 deb。

旧独立 EXE 首次需退出并安装新版，后续直接在应用内更新。Windows 和 macOS 尚未配置平台代码签名证书；macOS 未做 Apple 公证。Linux 自动更新适用于 AppImage，deb 使用系统包管理器。

更新前结束或重连使用旧二进制的 MCP 客户端。数据保存在本机，第三方客户端的访问权限由客户端配置决定。
