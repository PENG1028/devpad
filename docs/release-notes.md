DevPad 0.7 工作日志开发版

- 「整理」可选笔记、想法、疑问、资料，也能创建自定义类型。旧开发类型和引用草稿继续可用，标签可跨项目复用。
- 搜索支持图片文件名，类型、状态、标签和有图条件可以组合筛选。项目导航支持连续浏览和键盘操作，切换项目时保留草稿归属。
- 常规字重的中文、对齐的窗口按钮和分组操作菜单。导出默认使用原文与原图。
- 设置切换通用、工具、关于时保持窗口和标签的位置。20 种界面语言共用一份清单，支持跨窗切换、托盘和从右到左的界面。

- 项目支持右键和行内菜单删除，记录、草稿自动归入收件箱。输入框提供剪切、复制、粘贴和全选。
- 设置子页支持返回并恢复原标签和焦点，搜索快捷键可选 F、K、Shift+F。本地存储、更新说明和 MCP 配置沿用同一套展开控件和滚动条。
- macOS 标题栏使用系统红黄绿按钮，悬浮收放按平台管理窗口装饰。
- 复制按记录顺序带上正文和原图，同名图片共享明确的编号。可单独复制正文或图片。手动收起悬浮笔记本可保留选择和草稿。
- 可选和自定义导出模板，多选完整导出所有图片与对应清单。
- 编辑草稿自动保存，关闭与退出后可恢复。
- 本地 stdio MCP：笔记、原图、已发布任务的领取、续期、释放和结果回写。
- 乐观版本检查、任务租约与领取凭证，避免并发覆盖。
- 应用内开发版/稳定版更新，验证签名并在安装前备份数据库。
- Windows 固定安装位置及旧快捷方式迁移；macOS 两种架构；Linux AppImage 与 deb。

旧独立 EXE 首次需退出并安装新版，后续直接在应用内更新。Windows 和 macOS 尚未配置平台代码签名证书；macOS 未做 Apple 公证。Linux 自动更新适用于 AppImage，deb 使用系统包管理器。

更新前结束或重连使用旧二进制的 MCP 客户端。数据保存在本机，第三方客户端的访问权限由客户端配置决定。
